🚀 Quick Start Guide

Get started with Ather PFMEA System in 5 minutes

📋 Overview

The Ather PFMEA System is a comprehensive tool for managing Process Failure Mode and Effects Analysis with built-in authentication and role-based access control.

🔑 Default Login Credentials

Role Username Password Permissions
Admin admin admin123 Full access + User management
Engineer engineer engineer123 Add/Edit/Delete entries
Viewer viewer viewer123 Read-only access

🎯 Getting Started (5 Steps)

1 Login to the System
  • Open login.html in your browser
  • Use admin credentials: admin / admin123
  • Click "Sign In" or use Quick Login buttons
2 Configure Stations
  • Navigate to "Plant Infrastructure" from dashboard
  • Click on a station to add operations
  • Add operation codes and descriptions
  • Or use the pre-configured GA-10 to GA-110 stations
3 Add PFMEA Entries
  • Go to "Risk Assessment Form"
  • Fill in the form fields (Station, Operation, Failure Mode, etc.)
  • System auto-calculates Action Priority
  • Click "Save to Database"
4 Import Bulk Data (Optional)
  • Navigate to "Database Entry & Import"
  • Upload your Excel/CSV file
  • Map columns to PFMEA fields
  • Preview and confirm import
5 View & Manage Data
  • Go to "Central Data Ledger"
  • Use filters to find specific records
  • Click cells to edit (requires Engineer role)
  • Export data as CSV when needed

👥 User Management (Admin Only)

Adding New Users

  1. Login as admin
  2. Navigate to User Management page
  3. Click "Add New User"
  4. Fill in user details and select role
  5. User can now login with their credentials

Changing User Roles

  1. Go to User Management
  2. Click "Edit" on the user
  3. Enter new role (admin/engineer/viewer)
  4. Changes take effect immediately

📊 Key Features

  • Combine multiple filters
  • Export filtered results

Data Entry

⚠️ Important Notes

⚠️ Security Warning: This system uses browser localStorage for data storage. For production use, implement proper server-side authentication and database storage.

Data Storage

All data is stored locally in your browser. To backup data:

  • Export database as CSV regularly
  • Export audit trail for compliance
  • Keep backups of exported files

Browser Compatibility

  • Chrome (Recommended)
  • Firefox
  • Safari
  • Edge

Best Practices

  • Change default passwords immediately
  • Assign appropriate roles to users
  • Regular data exports for backup
  • Review audit trail periodically
  • Use strong passwords for new accounts

🆘 Troubleshooting

Can't Login

  • Check username and password (case-sensitive)
  • Clear browser cache and try again
  • Use Quick Login buttons for demo accounts

Session Expired

  • Sessions expire after 8 hours (24 hours with "Remember Me")
  • Simply login again to continue

Can't Edit/Delete

  • Check your user role (Viewers have read-only access)
  • Contact admin to upgrade your role

Import Not Working

  • Ensure file is .xlsx, .xls, or .csv format
  • Check that required columns are present
  • Map columns correctly in the mapping screen
